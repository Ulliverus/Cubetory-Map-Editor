This is the GitHub page of the Cubetory Map Editor!

Here, you will find all the project source files and download the (latest) release(s) of the Editor!

To download, click on "releases" and select the one you want to download.
Once you have it installed, unpack the zip and the Editor is ready to use!

To run the executable, do not move it from its original position in the Zip-file.

If you find any bugs or similar issues, or have an idea how to improve this Editor, let me (Ulliverus) know via the Issues page right here on Github.

Have fun!
